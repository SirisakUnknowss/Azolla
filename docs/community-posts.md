# โพสต์ชุมชน — Azolla

ร่างโพสต์สำหรับกระจายลิงก์เว็บ **https://sirisakunknowss.github.io/Azolla/**
คำถามทุกข้อในโพสต์คัดมาจาก `src/data/pool/` และ `src/data/content.th.ts` จริง
(ไม่ได้แต่งใหม่) ฉะนั้นคนที่กดเข้าไปจะเจอของแบบเดียวกับที่อ่านในโพสต์

เส้นแบ่งฟรี/จ่ายตาม `src/subscription/config.ts`:
ฟรี = เลเวล 1–5, เด็ค New friend / Colleague / Stranger, แพ็ค "เพิ่งเจอกันคืนแรก"
และ "ไม่เจอกันนาน" · Pro = เลเวล 6–10, เด็ค Lover / Best friend / Old friend /
Family, แพ็ค "คุยกันหลังเที่ยงคืน" และ "ปรับความเข้าใจ", เขียนคำถามเองได้

## กฎ 5 ข้อก่อนโพสต์ (อ่านก่อน ไม่ต้องเสียแอคฟรี)

1. **ลิงก์อยู่คอมเมนต์แรกเสมอ** — กลุ่มไทยส่วนใหญ่ลดการมองเห็นโพสต์ที่มีลิงก์
   ออกนอกแพลตฟอร์ม และบางกลุ่มลบทิ้งเลย ตัวโพสต์ต้องอ่านจบได้ด้วยตัวเอง
   แม้ไม่กดลิงก์
2. **อย่าโพสต์ข้อความเดียวกันหลายกลุ่มในวันเดียว** — Facebook อ่านเป็นสแปม
   เว้นอย่างน้อย 1 กลุ่ม/วัน และสลับคำขึ้นต้นทุกครั้ง
3. **ห้ามเอ่ยถึง Dark mode / Sex mode ในที่สาธารณะ** — สองเด็คนี้มีคำถามสำหรับ
   ผู้ใหญ่ ถ้าโพสต์ในกลุ่มทั่วไปหรือยิงแอดจะโดนจำกัดการมองเห็นหรือระงับบัญชี
   เก็บไว้สื่อสารในช่องทาง 18+ เท่านั้น
4. **อ่านกฎกลุ่มก่อนทุกครั้ง** — หลายกลุ่มต้องขออนุญาตแอดมินก่อนโพสต์ของตัวเอง
   ขออนุญาตทางข้อความก่อนเสียเวลา 1 นาที ดีกว่าถูกเตะออก
5. **ตอบทุกคอมเมนต์ในชั่วโมงแรก** — ยอดเอนเกจชั่วโมงแรกเป็นตัวตัดสินว่าโพสต์
   จะไปต่อหรือตาย และคนที่คอมเมนต์คือกลุ่มที่พร้อมจ่ายที่สุด

## 1. กลุ่มคู่รัก / ความสัมพันธ์

> ใช้กับ: กลุ่มคู่รัก, กลุ่มคนมีแฟน, กลุ่มเตรียมแต่งงาน, กลุ่มปรึกษาปัญหาความรัก

```text
คบกันนานแล้วเริ่มคุยกันแค่ "กินข้าวยัง" กับ "ง่วงยัง" ไหม

เราทำแอปการ์ดคำถามสำหรับนั่งคุยกันสองคนขึ้นมา เพราะบ้านเราเองก็เคยเป็นแบบนั้น
เอาคำถามจริงจากในแอปมาแปะไว้ให้เลย 7 ข้อ ลองเอาไปถามแฟนคืนนี้ก็ได้
ไม่ต้องกดอะไรทั้งนั้น

1. โมเมนต์ไหนที่ทำให้เธอรู้ตัวว่า "อยากคบกับคนนี้แหละ"?
2. เรื่องเล็ก ๆ น้อย ๆ อะไรที่เราชอบทำให้ แล้วถ้าวันไหนไม่ได้ทำเธอจะคิดถึงทันที?
3. นิสัยเสียของคู่เราสองคนที่แก้ไม่หายสักทีคือเรื่องอะไร?
4. มีเรื่องอะไรที่เธอแอบปรับตัวเพื่อเราเงียบ ๆ โดยไม่เคยพูดบ้าง?
5. ตอนไหนที่ทำให้เธอรู้สึกว่าเรารักและต้องการเธอมากที่สุด?
6. ลึก ๆ แล้วมีเรื่องอะไรที่เธออยากให้เราทำให้ แต่ไม่กล้าเอ่ยปากขอ?
7. เคยมีจังหวะไหนไหมที่นั่งอยู่ด้วยกันแท้ ๆ แต่กลับรู้สึกห่างเหินกันมาก?

ข้อ 1-3 คือเวอร์ชันเบา ๆ ข้อ 6-7 คือระดับที่ต้องเปิดใจจริง
กติกาที่บ้านเราใช้: ใครถาม คนนั้นต้องตอบข้อนั้นด้วย และห้ามเอาคำตอบ
ไปขึ้นในวงทะเลาะครั้งหน้า

ถ้าใครอยากได้เพิ่ม ในแอปมีประมาณ 700 ข้อ แบ่งเป็น 10 ระดับความลึก
เปิดจากลิงก์ในคอมเมนต์ได้เลย ไม่ต้องโหลด ไม่ต้องสมัคร
ฟรีถึงระดับ 5 และคำตอบไม่ถูกส่งไปไหนทั้งนั้น เก็บอยู่ในเครื่องเฉย ๆ
```

**คอมเมนต์แรก:**

```text
ลิงก์ครับ เปิดในมือถือได้เลย → https://sirisakunknowss.github.io/Azolla/
มีภาษาไทยและอังกฤษ สลับได้ในแอป ใครติดอะไรคอมเมนต์ถามได้ครับ
```

## 2. กลุ่มเพื่อน / ไลฟ์สไตล์ / คาเฟ่ / นั่งชิล

> ใช้กับ: กลุ่มหาเพื่อนคุย, กลุ่มคาเฟ่ฮอปปิ้ง, กลุ่มนั่งชิล, กลุ่มรวมรุ่น, กลุ่มมหาลัย

```text
เวลานัดเพื่อนเจอกัน แล้วคุยจบเรื่องงานกับเรื่องคนอื่นใน 20 นาทีแรก
เหลืออีกสองชั่วโมงนั่งเล่นมือถือกันทั้งโต๊ะ — ใครเป็นบ้าง

ลองใช้วิธีนี้ครั้งหน้า: วางมือถือคว่ำไว้กลางโต๊ะ แล้วไล่ถามคนละข้อ
คนที่ตอบคือคนที่ถูกถาม คนอื่นห้ามแทรกจนกว่าจะตอบจบ

9 ข้อที่ใช้ได้ทันที
- คนภายนอกมักจะเข้าใจผิดเรื่องอะไรเกี่ยวกับตัวคุณบ่อยที่สุด?
- คุณทำอะไรได้ดีมาก ๆ แต่ไม่ค่อยมีใครรู้เลย?
- มีเรื่องอะไรที่คุณเชื่อแบบจริงจังมาก แต่คนส่วนใหญ่ไม่ค่อยเชื่อกัน?
- มีเรื่องอะไรที่เมื่อก่อนแคร์มาก แต่ตอนนี้ปล่อยวางได้แล้ว?
- เวลาอยากหนีไปพักสมองคนเดียวสักชั่วโมง ชอบไปที่ไหน?
- เรื่องเล็ก ๆ น้อย ๆ อะไรที่เจอปุ๊บแล้วอารมณ์เสียไปทั้งวัน?
- คำแนะนำดี ๆ ข้อไหนที่มีคนเคยเตือน แต่คุณดื้อไม่ยอมฟังเลย?
- ครั้งล่าสุดที่รู้สึกว่าเจอเรื่องยากเกินรับไหวคือตอนไหน?
- ถ้าจบคืนนี้ไป อยากให้จำอะไรเกี่ยวกับตัวคุณได้มากที่สุด?

สี่ข้อแรกเรียกเสียงฮา สองข้อท้ายเปลี่ยนโต๊ะทั้งโต๊ะ ใช้ตอนใกล้กลับบ้าน

เราทำเป็นแอปการ์ดไว้ด้วย มีจับเวลาให้แต่ละคน (กันคนพูดยาว) และกดดาวเก็บ
ข้อที่ชอบไว้ได้ เปิดจากลิงก์ในคอมเมนต์ ไม่ต้องติดตั้ง ส่งต่อในไลน์กลุ่มได้เลย
```

## 3. กลุ่มวิทยากร / HR / ครูแนะแนว / พี่ค่าย

> ใช้กับ: กลุ่มวิทยากรกิจกรรมกลุ่มสัมพันธ์, กลุ่ม HR, กลุ่มครู, กลุ่มพี่ค่าย
> โทนนี้คือ "แจกเครื่องมือ" ไม่ใช่ขาย — และเป็นของฟรีจริง เพราะเด็ค
> Colleague/Stranger กับเลเวล 1–5 ไม่เสียเงิน

```text
แจกเครื่องมือละลายพฤติกรรมที่ไม่ต้องเตรียมอะไรเลย

ปัญหาคลาสสิกของกิจกรรมเปิดวง: ให้แนะนำตัวเอง ทุกคนพูดชื่อ-ตำแหน่ง-จบ
ไม่มีใครจำใครได้ และ 10 นาทีแรกหายไปเปล่า ๆ

เราทำแอปการ์ดคำถามไว้ใช้งานตัวเอง แล้วคิดว่าสายกิจกรรมน่าจะใช้ต่อได้
เปิดเป็นเว็บ ไม่ต้องติดตั้ง ส่ง QR หรือลิงก์ให้ผู้เข้าร่วมเปิดในมือถือตัวเอง
จับคู่แล้วกดเล่นได้ทันที มีตัวจับเวลาต่อตา ตั้งได้ว่ากี่วินาที
และเลือกโหมดได้ว่าให้ผลัดกันถาม ถามข้างเดียว หรือข้ามข้อที่ไม่อยากตอบ

คำถามสำหรับวงคนทำงาน (ใช้ได้เลย ไม่ต้องอ้างอิงใคร)
- เอาจริง ๆ ในแต่ละวัน งานหลักที่กินเวลาชีวิตคุณมากที่สุดคืออะไร?
- ตอนเจอกันวันแรก ๆ เดาไว้ว่าเราเป็นคนนิสัยยังไงในการทำงาน?
- มีเรื่องอะไรในที่ทำงานนี้ ที่รู้งี้มีคนกระซิบบอกตั้งแต่วันแรกคงดี?
- ถ้ามีอำนาจสั่งเปลี่ยนอะไรในที่ทำงานนี้ได้โดยไม่โดนเด้ง อยากเปลี่ยนอะไร?
- มีไอเดียดี ๆ อันไหนที่เคยเสนอไปแล้วเงียบหายเข้ากลีบเมฆไปเลยบ้าง?

สำหรับวงที่ไม่รู้จักกันมาก่อนเลย
- วันนี้มีเรื่องอะไรที่คิดอยู่ในหัวตั้งแต่เช้า แต่ยังไม่ได้พูดออกมาเลย?
- ถ้ามีวันว่างหนึ่งวันแบบไม่ต้องทำหน้าที่อะไรเลย จะเอาเวลาไปทำอะไร?
- ย้อนไปตอนเด็ก ๆ สถานที่หรือช่วงเวลาไหนที่คุณมีความสุขที่สุด?
- ความเห็นหรือความชอบส่วนตัวเรื่องไหนของคุณที่คนอื่นมักจะไม่เข้าใจ?

เด็คคนทำงานกับเด็คคนไม่รู้จักกันเปิดใช้ได้ฟรีทั้งหมด (ระดับ 1-5)
ไม่ต้องสมัครสมาชิก ไม่เก็บข้อมูลผู้เข้าร่วม — คำตอบไม่ถูกส่งออกจากเครื่องเลย
ใครเอาไปใช้ในค่ายหรืออบรมแล้วติดอะไร คอมเมนต์บอกได้ครับ
อยากได้คำถามเพิ่มสำหรับกลุ่มแบบไหนบอกได้ เราเขียนเพิ่มให้
```

## 5. กลุ่ม Expat / Language exchange (โพสต์ภาษาอังกฤษ)

> ใช้กับ: Expats in Bangkok / Chiang Mai, Thai–English language exchange,
> กลุ่มคู่ไทย-ต่างชาติ · จุดขายคือคำถามเดียวกันมีสองภาษา สลับได้สด

```text
Built a conversation-card app that works for Thai–foreign couples,
because the usual ones don't

The wall we kept hitting: an English question deck is too abstract to translate
on the spot, and by the time the question has been explained the moment is gone.

So the app carries both languages for the same question — 700 of them, and you
switch TH/EN with one tap mid-session. Same card, same question, each person
reads it in their own language. The Thai isn't machine-translated; it's written
the way Thai people actually speak, so it doesn't read like a textbook.

A few, in both:

"What did you notice about me before we spoke?"
"ตอนเจอกันครั้งแรก ก่อนจะได้คุยกัน เธอสะดุดตาอะไรในตัวเราก่อนเลย?"

"What do you need from me that you have never asked for?"
"ลึก ๆ แล้วมีเรื่องอะไรที่เธออยากให้เราทำให้ แต่ไม่กล้าเอ่ยปากขอ?"

"What's a small thing that ruins your whole day?"
"เรื่องเล็ก ๆ น้อย ๆ อะไรที่เจอปุ๊บแล้วอารมณ์เสียไปทั้งวัน?"

It doubles as language practice — answer in your partner's language, then flip
the card to check how it's phrased.

It runs in the browser, no install, nothing to sign up for, and nothing you
answer leaves your phone. Free up to level 5. Link in the first comment.
```

**คอมเมนต์แรก:**

```text
Opens straight in a phone browser. Happy to add question sets if you have a
situation it doesn't cover.
```

## 6. กลุ่มนักพัฒนา / Indie Hackers (ขอฟีดแบ็ก ไม่ใช่ขาย)

> ใช้กับ: Thai Programmer, React Native Thailand, Indie Hackers Thailand
> กลุ่มนี้ไม่ชอบโพสต์ขาย แต่ชอบเรื่องเทคนิคกับของจริง

```text
เขียนแอปการ์ดคำถามด้วย Expo แล้วปล่อยเป็นเว็บก่อนลงสโตร์ — มาขอฟีดแบ็กครับ

ของจริงคือ React Native + Expo โค้ดชุดเดียวออกได้ทั้ง iOS / Android / เว็บ
ที่เลือกปล่อยเว็บก่อนเพราะแอปประเภทนี้คนใช้ตอนนั่งอยู่ด้วยกัน
ถ้าต้องให้อีกฝ่ายโหลดแอปก่อนคือจบแล้ว ส่งลิงก์ในไลน์แล้วเปิดเล่นได้เลยจบกว่า

สิ่งที่เจอตอนทำ เผื่อมีใครกำลังทำแนวสองภาษา
- คำถามไทย/อังกฤษเก็บเป็น tuple เดียวกัน แปลหลุดข้างเดียวไม่ได้
- key ของคำถามเป็น hash ของประโยคอังกฤษ เพิ่ม/ลบ/สลับข้อแล้ว state ที่เซฟไว้ไม่เพี้ยน
```
